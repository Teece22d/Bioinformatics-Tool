# Bioinformatics Web Application

A full-stack MERN (MongoDB, Express.js, React, Node.js) application for protein-genome sequence analysis.

## Features

- User authentication (login/signup)
- Secure file upload for protein and genome sequences (.txt format)
- Configurable similarity threshold for sequence matching
- Real-time sequence analysis
- Results visualization with match details
- Analysis history tracking
- Responsive design

## Prerequisites

- Node.js (v16 or higher)
- MongoDB (running on your home server)
- npm or yarn package manager
